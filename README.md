# TypingSpeedTest

Java Swing-based app to test typing speed and accuracy with real-time WPM, CPM, accuracy stats, and timed typing challenges.

# Configurations

Random sentence generation every test
Real-time timer
Calculates Words Per Minute (WPM) and accuracy
Start / End test on the same toggle button
Restart button (only visible during test)
Persistent Scoreboard with all attempts
Clear Scores button to reset scoreboard
Theme toggle between light and dark modes
Fullscreen & responsive layout
Press Enter key to end the test early

# Installation

1. **Install Java JDK 8+** from [Oracle](https://www.oracle.com/java/technologies/javase-downloads.html) and verify with `java -version`.  
2. **Install an IDE** like IntelliJ, Eclipse, or NetBeans for easier code editing and running.  
3. **Create a project folder** and add your `TypingSpeedTest.java` source file.  
4. **Compile and run the program** using `javac TypingSpeedTest.java` and `java TypingSpeedTest`.  
5. **Use the GUI** to take the typing test and view your speed and accuracy.
